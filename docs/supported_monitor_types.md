# Supported Monitor Types

## 初版で確認済み

| 監視タイプ | 状態 | 備考 |
| --- | --- | --- |
| `Custom2` | 対応 | 一覧表示、詳細表示、`Options` のベストエフォート抽出を実装 |

## 汎用対応

- 未知の監視タイプでも XML の全項目は保持する。
- `監視項目一覧` には `Type` の元値をそのまま出力する。
- 専用の意味付けは行わず、`XML全項目` シートで確認できるようにする。

## 実測確認済み監視タイプ

- `DiskQueueLength`
- `Custom2`

## 未対応事項

- 監視タイプごとの専用列追加は `Custom2` 以外まだ未実装。
- イベントログ監視、サービス監視、パフォーマンスカウンター監視の専用解釈は次イテレーション候補。
