ディスクパフォーマンス監視 監視テンプレート ReadMe
===================================================
セイ･テクノロジーズ株式会社
最終更新日：2026/07/29

--------
はじめに
--------

本ドキュメントは、BOM for Windows Ver.8.0 (BOM 8.0)用の
「ディスクパフォーマンス監視 監視テンプレート」について記述しています。


--------
環境条件
--------

本監視テンプレートは、以下の条件を満たしている場合にご利用頂けます。

・BOM 8.0 の動作要件を満たし、正常にインストールされ動作していること。


------------------
テンプレートの詳細
------------------

本テンプレートを、BOM 8.0 で動作する Windows 監視インスタンスに
インポートすることにより、簡単に設定できます。

・本テンプレートには、以下の監視項目が含まれます。

項目名												|初期値	
--------------------------------------------------------------------------------------------------------
+ ディスクパフォーマンス監視									|有効
 - レイテンシ(ディスク転送時間)									|有効
 - スループット(ディスクの読み取り/書き込み速度)						|有効
 - IOPS												|有効
 - ディスク（論理ドライブC: ）のアクティブな時間						|有効


--------
注意事項
--------
・テンプレートの各監視項目に設定済みの閾値及び監視間隔等は、弊社で検証の
  結果設定した値です。ご利用環境や要件にこれらの設定値が適合しない場合が
  有ります。その場合は設定値を環境や要件に適合した値に変更してお使いくだ
  さい。


------------------
テンプレートの導入
------------------

テンプレートの導入は、以下の2通りの方法で行えます。どちらの方法で導入
しても導入結果に差異は有りませんので、要件に合った方法をお選びください。

●「テンプレートのインポート」からの導入
BOM 8.0 のテンプレートが保存されているディレクトリへ本テンプレートを
コピーした後に導入を実行する方法です。複数の対象となる監視インスタンスが
存在し、其々に導入する場合に判りやすい方法です。

 1. ダウンロードしたアーカイブを、監視元となる Windows コンピューターの
    任意のディレクトリに展開し、以下の内容を確認します。
      - 1111_ディスクパフォーマンス監視.cab
      - 1111_ディスクパフォーマンス監視.htm
      - ディスクパフォーマンス監視 監視 ReadMe.txt (本ドキュメント)

 2. 前項で展開したファイルの内、以下の 2 ファイルを BOM 8.0 のテンプレート
    ディレクトリへコピーします。
      - コピー対象ファイル
	- 1111_ディスクパフォーマンス監視.cab
	- 1111_ディスクパフォーマンス監視.htm
      - コピー先ディレクトリ
	<[BOM インストールディレクトリ]\SAY Technologies\BOMW8\Common\TemplateData\0000_標準構成テンプレート>

 3. BOM 8.0 マネージャーを起動し、「BOM for Windows Ver.8.0 (ローカル)」へ
    接続します。(リモート接続の場合は、インポート先スナップインへ接続します。)

 4. 監視が実行されている場合には、停止します。

 5. テンプレートの導入先インスタンスを右クリックし、「テンプレートのイン
    ポート」を選択します。

 6. 「テンプレートフォルダー」に表示されている「標準構成テンプレート」を
    クリックします。

 7. 「テンプレートの設定」に表示された「ディスクパフォーマンス監視」を
    クリックし、プレビュー欄に表示されている内容を確認します。

 8. 「インポート」ボタンをクリックし、インポートを実行します。

 9. BOM 8.0 マネージャー上から、正常にインポートされていることを確認します。

10. 監視を開始します。

※「テンプレートのインポート」操作時の注意事項※

・「テンプレートのインポート」操作でリモート接続のスナップイン配下のイン
  スタンスへ導入する場合、「テンプレートのインポート」により参照される
  ディレクトリは BOM 8.0 マネージャーが動作しているコンピューター上のテン
  プレートディレクトリとなり、リモート接続先のコンピューターのテンプレート
  ディレクトリは参照されません。


●「監視設定のインポート」からの導入
アーカイブを展開したディレクトリより直接インポートを行う方法です。
こちらでは、テンプレートのインポート時に確認できる設定内容の確認が出来ず、
また、BOM 8.0 のテンプレートフォルダへのファイルコピーも実行されません。

 1. ダウンロードしたアーカイブを、監視元となる Windows コンピューターの
    任意のディレクトリに展開し、以下の内容を確認します。
      - 1111_ディスクパフォーマンス監視.cab
      - 1111_ディスクパフォーマンス監視.htm
      - ディスクパフォーマンス監視 監視 ReadMe.txt (本ドキュメント)

 2. BOM 8.0 マネージャーを起動し、「BOM for Windows Ver.8.0 (ローカル)」へ
    接続します。(リモート接続の場合は、インポート先スナップインへ接続します。)

 3. 監視が実行されている場合には、停止します。

 4. 導入先インスタンスを右クリックし、「監視設定のインポート」を選択します。

 5. ファイル選択ダイアログで、項番 1.でアーカイブを展開したディレクトリを
    表示します。

 6. 「1111_ディスクパフォーマンス監視.cab」を選択し、「開く」ボタンをク
    リックします。

 7. BOM 8.0 マネージャー上から、正常にインポートされていることを確認します。

 8. 監視を開始します。
